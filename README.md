# Investment Selection Optimization

Python project comparing Greedy and Dynamic Programming.

## Investment Types

- Gold
- Bitcoin
- Apple Stock
- Government Bonds
- Fixed Deposit
- Real Estate

The values are fictional and used only for academic demonstration.

## Commands

Run terminal version:

```bash
python main.py
```

Run the browser frontend:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Run performance test:

```bash
python performance_test.py
```

Run tests:

```bash
python -m unittest discover -s tests -v
```
